# Silver's Mass Transport app

Currently compatible with one service using "http://info.skopska.mk:8080" for stops, lines and information about when buses are scheduled (live and non live info), and undocumented "wss://jspotg.stormwin.mk" API for gps tracking.

Runs on Linux, Android, Windows.

Builds for web (WASM) but can't work because CORS.
